Content demo box

Cách tính tổng chiều rộng (Total Width):

Tổng chiều rộng chiếm chỗ của phần tử trên trang là 360px, chi tiết gồm:

  • Width (Nội dung): 200px
  • Padding (Trái + Phải): 35px + 35px = 70px
  • Border (Trái + Phải): 20px + 20px = 40px
  • Margin (Trái + Phải): 25px + 25px = 50px

👉 Công thức: 200 + 70 + 40 + 50 = 360px
